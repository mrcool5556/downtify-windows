**Updates from inside the app.** Settings shows a dot when a new version is out. Settings → About lists every release since yours with its notes, and **Update to x.y.z** downloads the installer from GitHub, checks it against the checksum GitHub publishes for it, installs silently and restarts Downtify. No sign-in, no key, nothing uploaded. Settings, library and downloads stay. This is the last version you need to install by hand.

Also: the Settings page remembers which section you were on, and the About page no longer opens the browser for updates.

Unsigned installer: Windows SmartScreen may warn on first run.
