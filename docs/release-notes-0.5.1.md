**Lyrics.** The new lyrics button next to repeat opens the lyrics of the song playing, over the song list. Synced lyrics follow along: the line being sung lights up and stays in the middle, and clicking a line jumps the song there. Saved songs use the lyrics your Downtify server already stored; LRCLIB is asked only when the server has none or the song is only streaming. Esc or the button again closes it.

**Arrange your playlists** (needs Downtify 3.10 or newer):
- Playlists show each song's place number. Drag songs up and down to reorder them; the new order is saved to the server.
- Click **#** to flip the list last-to-first, and again to go back.
- Adding songs that are already in a playlist asks **Add duplicates** or **Don't add duplicates**.
- Removing a song that's in a playlist twice takes out only the copy you picked.

**Quicker selecting and adding:**
- **Ctrl+A** selects every song in the list.
- Drag the playing song (cover and title in the player bar) onto a playlist in the sidebar to add it.

**No more browser menus.** Right-clicking anywhere no longer shows the browser's Back / Refresh / Print / Inspect menu. Text boxes get the app's own **Cut, Copy, Paste and Select all**, and right-clicking a misspelled word offers fixes from your own song, artist and album names (so "hethens" → Heathens, and band names aren't flagged as typos).

Updating from 0.5.0: Settings → About → Update. Unsigned installer: Windows SmartScreen may warn on a fresh install.
